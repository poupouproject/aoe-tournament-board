# Tournois FDS Gaming

Les scoreboards de la fin de semaine de gaming annuelle entre amis, affichés sur
projecteur. On change de jeu presque chaque année, alors chaque édition vit
dans son propre dossier, indépendant des autres. On les garde pour pouvoir les
relancer ou s'en inspirer l'année suivante.

| Édition | Jeu                                   | Dossier                                        | Techno          |
| ------- | ------------------------------------- | ---------------------------------------------- | --------------- |
| 2026    | Need for Speed Hot Pursuit Remastered | [`2026-hot-pursuit/`](2026-hot-pursuit/)       | Next.js, SQLite |
| 2023    | Age of Empires II: Definitive Edition | [`2023-age-of-empires/`](2023-age-of-empires/) | HTML, CSS, JS   |

## Nouvelle édition

Créer un dossier `AAAA-nom-du-jeu/`, avec son propre README. On peut copier
l'édition la plus proche comme point de départ.
